# engine/render

Isometrischer 2D-Renderer: Sprite-Atlanten aus BSH-Dateien, Batching über die SDL3-GPU-API, drei Zoomstufen (später stufenlos), beliebige Auflösungen. Liest den Simulationszustand nur. **Meilenstein:** M2.
